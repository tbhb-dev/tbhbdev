# Structurizr macro reference

Load `structurizr_workspace` from `@tbhb_rules_structurizr//:defs.bzl`. Paths are relative to the target package.

```starlark
structurizr_workspace(
    name = "architecture",
    dsl = "docs/architecture/workspace.dsl",
    workspace_json = "docs/architecture/workspace.json",
```

## Targets and checks

- Run `bazel run :architecture` to refresh committed JSON and images and remove orphan images. Declare local imports in `data`.
- Build `:architecture.renders` for JSON, PlantUML text, SVG, and PNG exports. Each view has a main diagram and a legend.
- Run `:architecture_test` for lint, freshness, and PNG checks.
- Lint always runs `validate -w` and `inspect -w -s error,warning`. Inspections with severity `ERROR` or `WARNING` fail. Severities `INFO` and `IGNORE` pass. Command errors fail too. The runner also looks for violation lines in what `inspect` prints. Other output passes.
- Freshness compares JSON and SVG bytes. The Java virtual machine uses Coordinated Universal Time (UTC) and the en_US.UTF-8 locale. Missing or orphan SVGs and PNGs fail on every platform.
- The PNG test compares bytes on Linux x86_64, where the update target writes PNGs. Preserve generated bytes in Git and exclude them from text formatters.
- Rendering uses a pinned Java runtime in headless mode and `!pragma layout smetana`. Graphviz is unnecessary. Java HTTP and HTTPS requests use an unreachable proxy. PlantUML uses its sandbox security profile.
- The renderer uses IBM Plex Sans from the four TrueType files bundled with the module. On Linux, a generated `FONTCONFIG_FILE` points to the bundled directory and a scratch cache. Linux rendering requires `libfontconfig` and `libfreetype`. The renderer checks that the JVM uses the bundled TrueType files and that each SVG specifies IBM Plex Sans.
- Treat workspace sources as trusted input. The `!script`, `!plugin`, and absolute `!include` directives can access the host despite the HTTP(S) proxy and PlantUML sandbox. The pinned command-line tool doesn't expose a restricted mode for validation, inspection, or export. Use trusted workspace sources and imports. Name the source `workspace.dsl`.

## Tool pins

- Keep literal `http_archive` and `http_file` declarations in `pins/extensions.bzl`. They pin the Structurizr command-line tool at 2025.11.09, the Temurin Java runtime at 21.0.13+9, and the PlantUML MIT build at 1.2026.10. Bazel verifies Secure Hash Algorithm 256 digests. Renovate reads versions from the release URLs of Structurizr, PlantUML, and Temurin. Update the Temurin `strip_prefix` by hand.
- Use `override_repo` to replace the `tbhb_rules_structurizr_cli`, `tbhb_rules_jre`, or `tbhb_rules_plantuml` hub. Java runtime pins cover Linux and macOS on x64 and arm64.
- Download each release asset outside the source tree before updating pins. Compute its digest and compare published checksums. Change each URL, digest, and archive prefix together. Repeat lint, failure proofs, and rendering stability measurements before updating fixtures.
- Preserve upstream license notices in downloaded repositories. Structurizr uses `Apache-2.0`, the PlantUML build uses `MIT`, and Temurin uses `GPL-2.0` with the Classpath exception. Bundled IBM Plex Sans uses the SIL Open Font License 1.1 (`OFL-1.1-RFN`).
